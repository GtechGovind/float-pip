# Changelog

## 1.0.0 — 2026-11-17

- Initial open-source release of Float PiP by Qurkos.
- Native PiP helper, visible-video selection, same-origin frame/open-shadow discovery and direct-click fallback.
- Temporary tab permissions and bundled code; no analytics or persistent host access.
- Chrome, Edge and Firefox submission packages with deterministic builds.
- Firefox built-in PiP guidance when the standard API is unavailable.
- Community contribution, security reporting and CI setup.

The GitHub release provides unsigned developer/submission archives. Browser-store review and signing are separate; see [release status](docs/RELEASE-STATUS.md).
