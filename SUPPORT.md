# Support Float PiP

Float PiP is a free, MIT-licensed Qurkos project maintained by Govind Yadav.

## Get help

For ordinary bugs or questions, [open an issue](https://github.com/GtechGovind/float-pip/issues/new/choose) after checking existing reports. Include your browser version and reproduction steps. For private security reports, read [SECURITY.md](SECURITY.md).

## Contribute

Testing, documentation, accessibility improvements, bug fixes and sharing the project all help. See [CONTRIBUTING.md](CONTRIBUTING.md). A star helps other users discover the project.
