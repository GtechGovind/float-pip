Float PiP

By Govind Yadav · qurkos.com

Keep a video nearby while you do something else.

Open your video

  1. Start a video on a normal website.
  2. Click the Float PiP toolbar icon, then Open picture-in-picture.
  3. If the browser needs another gesture, close the popup and use the Float PiP button that appears on the page.

Use the button again to return the video. Keep its original tab open. After a full navigation, activate the extension again. On episode changes within the same page, restrictions are cleared for replacement videos; if PiP closes, open it again.

Firefox

Where the standard PiP API is available, Float PiP requests it. On older Firefox versions it clears the website’s PiP hint, then you use Firefox’s own PiP icon over the video. If needed, hold Shift and right-click the video to show the browser menu, then choose Watch in Picture-in-Picture. Menu labels vary with language and browser version. Enable PiP in Firefox settings if the control is missing.

Keyboard

Alt + Shift + P opens the extension controls. Press Enter once the main button is focused to open PiP. Change the shortcut in Chrome at chrome://extensions/shortcuts, Edge at edge://extensions/shortcuts, or Firefox under Add-ons Manager → gear menu → Manage Extension Shortcuts. If the shortcut conflicts, assign a different one.

Player limitations

Float PiP works with accessible HTML5 videos, including video inside open shadow roots and permitted frames. Start playback and keep the video visible while scanning. Other-origin embedded players may require opening the player’s own website. Closed shadow roots, protected browser pages, browser settings, DRM restrictions, and site Permissions Policy can prevent PiP. Site captions, interactive overlays and controls may stay in the original page. No extension can guarantee every video on every platform.

Netflix, Crunchyroll and YouTube are examples of sites to test, not endorsements or guaranteed compatibility. Float PiP is an independent project and is not affiliated with these services. It does not bypass subscriptions, DRM or access restrictions.

Privacy

Float PiP collects and transmits no personal data. It uses no analytics, advertising, accounts, remote scripts or external services. When you open its controls, it inspects video readiness and geometry only in accessible frames of the active tab; that information is used temporarily in memory. When activated, it removes the video’s PiP restriction hint and watches for player changes in that document until it is unloaded. It does not save browsing history, website contents, or video URLs.

Permissions: activeTab grants temporary access after you invoke the extension. scripting runs its bundled video helper in that tab. It requests no persistent website access.
