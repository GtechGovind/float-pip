# GitHub Sponsors setup

Selected platform: **GitHub Sponsors**, personal account **GtechGovind**, maintained by Govind Yadav for the Qurkos Float PiP project.

## Enrollment

1. Open [GitHub Sponsors accounts](https://github.com/sponsors/accounts) while signed in as GtechGovind. Choose **Get sponsored** beside the personal account.
2. Complete GitHub's access verification privately.
3. Complete the required contact, payout, identity and tax information yourself. Review and accept the applicable terms if you agree. Do not commit those details to this repository or post them in issues.
4. Set up the public profile and sponsorship tiers, then request GitHub approval.
5. After approval, verify that the public Sponsors profile can receive sponsorships. Uncomment `github: GtechGovind` in `.github/FUNDING.yml` and update `SUPPORT.md` with the active link.

GitHub's [official setup guide](https://docs.github.com/en/sponsors/receiving-sponsorships-through-github-sponsors/setting-up-github-sponsors-for-your-personal-account) describes the current requirements. Enrollment and approval are separate from repository setup.

## Suggested public profile copy

**Short bio:** Govind Yadav builds Qurkos open-source tools, including Float PiP for desktop browsers.

**Introduction:** I maintain Float PiP, an MIT-licensed helper for opening accessible videos in browser picture-in-picture. Sponsorship supports time spent on browser compatibility testing, accessibility, documentation and maintenance. The extension remains free, and contributions are welcome whether or not you sponsor. Sponsorship does not guarantee individual support or unlock paid features.

Use support-only tiers without promised delivery dates or private access unless you choose to offer and maintain those benefits.
